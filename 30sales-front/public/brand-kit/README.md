# 30sales — kit de marca v1

Conceito aprovado: **Conexão e Fluxo**. Uma seta dentro do 0 representa a jornada do lead até a conversão.

## Conteúdo
- `logos/`: logotipo horizontal SVG e PNG, com versões para fundo claro e escuro.
- `icons/`: ícone quadrado em SVG, PNG e favicon.ico.
- `branding/`: tokens de cores e tipografia em JSON e CSS.
- `CODEX_PROMPT.md`: instruções de integração no projeto.

## Uso
- Em fundos claros: `logos/logo-default.svg`.
- Em fundos escuros: `logos/logo-light.svg` ou `logos/logo-on-dark.svg`.
- App: `icons/icon-dark.svg`, `icons/icon-192.png`, `icons/icon-512.png`.
- Fontes: Manrope (display) e Inter (interface). Carregar via Google Fonts ou hospedagem própria, respeitando licenças.

## Observações
Arte vetorial original criada para este pacote; não é uma extração fiel dos mockups conceituais anteriores. SVGs usam texto editável e podem depender da fonte instalada; para impressão, converter texto em curvas no editor vetorial. Validar legibilidade e uso antes de registrar marca.
